<h1>Overview</h1>
This mod patches select classic Infinity Engine games to resolve a freezing issue caused by Windows 11.
<br>
<br>

<h1>Compatibility</h1>

Game versions:

- oIWD v1.42 (062714)
- oBG2 v2.5.26498 (Non-TobEx)

Dependencies:

- <a href="https://aka.ms/vs/17/release/vc_redist.x64.exe/">Microsoft Visual C++ Redistributable</a>
<br>

<h1>Download</h1>
The latest version can be downloaded from the <a href="https://github.com/Bubb13/B3-IE_Win11_Fixes/releases">Releases</a> page. The archive is located under the collapsible "Assets" menu.
<br>
<br>

<h1>Installation</h1>
Extract the archive's contents into your game directory and run the setup file to install.
<br>
<br>

<b>Note:</b> The game must be started using `InfinityLoader.exe` after installation; starting the game using the vanilla executable will not apply the mod's fixes. If `InfinityLoader.exe` fails to start, please ensure you have installed the latest <a href="https://aka.ms/vs/17/release/vc_redist.x64.exe/">Microsoft Visual C++ Redistributable</a>.
